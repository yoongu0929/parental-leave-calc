# 육아휴직 급여 계산기

월 통상임금과 휴직 기간을 입력하면 육아휴직 급여의 월별 예상 지급액을 계산해 보여주는 웹 도구입니다.
화면 정의서·기능 정의서(v0.1)를 구현한 첫 버전이며, 모든 계산은 브라우저에서만 이뤄지고 서버로 전송되지 않습니다.

## 실행

```bash
npm install
npm run dev        # http://localhost:3000
npm test           # 계산·검증 단위 테스트
npm run typecheck
npm run build
```

## 구조

| 경로 | 역할 |
|---|---|
| `config/benefit.ts` | 급여 기준(지급률·상한·하한·기준일). 제도가 바뀌면 여기만 수정 |
| `lib/calculate.ts` | 순수 계산 함수 (FN-03) |
| `lib/validate.ts`, `lib/format.ts` | 유효성 검사, 입력 포맷팅, 연월 계산 (FN-01, 02, 07) |
| `components/` | 입력 폼, 결과 요약, 월별 표, 계산기 컨테이너 |
| `app/page.tsx`, `app/guide/page.tsx` | SCR-01 계산 메인, SCR-02 계산 기준 |
| `tests/` | TC-01~10과 기준 설정 무결성 테스트 |
